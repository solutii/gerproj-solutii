REGRAS IMPORTANTES
------------------

  * NUNCA copie a pasta node_modules para o servidor.
    O pnpm usa "junctions" que guardam o caminho absoluto de onde foram
    criadas, então uma cópia quebra no servidor.

  * Instale sempre com PNPM (nunca "npm install").
    Só o pnpm aplica o patch do node-firebird (patches\node-firebird.patch),
    que corrige os acentos (banco em WIN1252). Sem ele, os acentos ficam
    corrompidos ao ler e ao gravar no banco.
    (Precisam existir no servidor: pnpm-workspace.yaml e a pasta patches\)

  * Não use "--no-frozen-lockfile" no servidor: ele resolveria versões
    diferentes das que você testou.

  * A porta de PRODUÇÃO é 3000. A 3001 é só do "pnpm dev" na sua máquina.


PROBLEMAS CONHECIDOS
--------------------

  Sistema não sobe / erro de módulo depois de trocar o .next (versão Next 15)
    -> Faltou reinstalar as dependências no servidor. Copie package.json e
       pnpm-lock.yaml e rode: pnpm install --frozen-lockfile --prod

  Erro: Cannot find module 'styled-jsx/package.json'
    -> O node_modules foi copiado. Apague e reinstale no servidor:
           Remove-Item -Recurse -Force node_modules
           pnpm install --frozen-lockfile --prod

  Erro: ERR_PNPM_OUTDATED_LOCKFILE
    -> O pnpm-lock.yaml do servidor está desatualizado em relação ao
       package.json. Copie o pnpm-lock.yaml da sua máquina.

  ERR_CONNECTION_TIMED_OUT no navegador
    -> Confira se o servidor está na porta 3000 (linha "Local:" no console).
       Teste abrir http://localhost:3000 no próprio servidor: se abrir lá, o
       bloqueio é de rede (firewall / redirecionamento de porta).

  Depois do login, o navegador vai para "localhost:3000/home"
    -> Faltou NEXTAUTH_URL no .env do servidor (veja acima). Basta corrigir
       e reabrir o .bat; não precisa de novo build.

  Acentos aparecendo como "Ã§" ou "�"
    -> O patch do node-firebird não foi aplicado (instalou sem pnpm).
       Para verificar, no PowerShell do servidor (deve retornar 2 linhas):

           Select-String -Path "C:\GERPROJ\web-app-2\node_modules\.pnpm\node-firebird*\node_modules\node-firebird\lib\wire\serialize.js" -Pattern "PATCH \(gerproj-solutii"
